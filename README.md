# Debug Builder Backend

Stateless Android WebView APK/AAB build orchestrator.

## Requirements
- Node 20
- Vercel account (Hobby fine for personal use)
- GitHub repo (public recommended for direct APK download)
- Android SDK (auto-installed by GitHub Actions)

## Setup

### 1. Create GitHub repo

```bash
git init
git add .
git commit -m "init"
git remote add origin https://github.com/YOURNAME/debugbuilder-backend.git
git push -u origin main
